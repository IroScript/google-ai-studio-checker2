# KidsTube

KidsTube is an Android video player application designed specifically for toddlers and young children, featuring parent-controlled settings, local folder/video selection, safe video playback, and toddler lock.

---

## 🚀 How to Download the APK from GitHub (Automated CI/CD)

This repository includes a pre-configured **GitHub Actions Workflow** (`.github/workflows/build-apk.yml`).

### Option 1: Automatic Build on Every Push
- Whenever code is pushed to `main` or `master`, GitHub Actions automatically compiles and packages the APK.

### Option 2: Manual 1-Click Trigger ("Run workflow")
1. Go to your repository on GitHub: `https://github.com/IroScript/kids_tube_with_folder_seection`
2. Click on the **Actions** tab at the top.
3. In the left sidebar, click **Build Android APK**.
4. Click **Run workflow** button on the right, select your build type (Debug / Release), and click **Run workflow**.

### 📥 Where to Download the Built APK:
1. Go to the **Actions** tab in GitHub.
2. Click on the latest workflow run (with a green checkmark ✅).
3. Scroll down to the **Artifacts** section at the bottom of the summary page.
4. Click on **KidsTube-APK** to download your ready-to-install Android APK file!
